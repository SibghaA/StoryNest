# Peer evaluation template

Used at the end of each sprint. Completed privately by each contributor and
submitted to the professor; a sanitized summary lives in the sprint retro.

## My contribution

- **Issues I closed this sprint:**
- **Biggest technical call I made:** <and one sentence on the tradeoff>
- **What I learned:**

## My partner's contribution

- **Issues they closed this sprint:**
- **Where I relied on them:**
- **One thing they did that I would not have thought of:**
- **One thing we could change to collaborate better next sprint:**

## Shared rating (1–5)

| Dimension                                                  | Self | Partner |
| ---------------------------------------------------------- | ---- | ------- |
| Ownership — picked up issues without prompting             |      |         |
| Quality — code landed green, didn't create follow-up fires |      |         |
| Communication — standups, PR comments, blocker escalation  |      |         |
| Reliability — delivered on what they committed in planning |      |         |
| Growth — visibly better at something vs. start of sprint   |      |         |

## Free text

Anything that should not be in the retro but the professor should see.
