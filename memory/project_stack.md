StoryNest is a Next.js 15 App Router app deployed on Vercel, using Prisma with SQLite locally and PostgreSQL in production. Auth is NextAuth.js with email/password (Google OAuth is backlog). Stories are generated by streaming `claude-sonnet-4-5` via the Anthropic SDK directly into a `ReadableStream`. Illustrations are generated asynchronously via fal.ai `fal-ai/flux/schnell` after the story text stream closes.

**Why:** These were chosen for speed of development — Next.js + Vercel removes infra decisions, Prisma handles the SQLite-to-Postgres swap transparently, and streaming from the Anthropic SDK natively into a Next.js route handler is well-supported.

**How to apply:** When adding new routes or features, assume App Router conventions (server components, route handlers in `app/api/`). Any new AI calls go through a route handler — never from a client component.
